# 中文写作优化

提示词在 [提示词.md](./提示词.md) 中，可打开后复制全文使用。

原创作者为 **duke**。下面的用法、模型排序与效果判断，来自作者使用这份提示词的体验。

## 1. 复制到聊天模式中使用

复制提示词全文，先填写最上面的“本次任务与特别要求”，再把原稿和必要材料放到末尾的对应位置，一起粘贴到 AI 或 Agent 的聊天模式中发送。

优先在网页端、聊天端使用，效果更好。不要在各种 IDE、GPT Work 这类工作环境中使用；WorkBuddy 勉强也可以用。

## 2. 不要做成 Skill

直接把提示词放进聊天里使用。不要把它做成 Skill，做成 Skill 后表现也会不好。

## 3. 一定要用最聪明的大模型

这份提示词需要模型充分理解和执行。选择平台时，也要记得选该平台最聪明、能力最强的模型。

作者的推荐顺序是：

| 优先顺序 | 模型 | 使用体验 |
| --- | --- | --- |
| 第一 | Gemini 4 | 最推荐；Gemini 的其他模型勉强也可以 |
| 第二 | Claude | 次选 |
| 第三 | 豆包 | 排在 Claude 之后 |
| 第四 | GPT、DeepSeek | 这两家的表现都极其一般 |

## 4. 把任务要求写清楚

使用时，最需要花心思的是开头的“本次任务与特别要求”。同一份原稿，修改权限、重点和预期阅读感受不同，交给模型的任务就不同。建议把下面四项说清楚。

- **修改权限**：分别说明能否调整结构逻辑、能否改变信息和观点、能否润色文本。这几项权限并不相同。允许润色，不等于允许重组结构；允许调整结构，也不等于允许增删信息或改变观点。哪些部分可以大改，哪些必须保留，都可以直接写明。
- **修改重点**：风格模仿、语流梳理、文本润色、AI 痕迹去除、增补和延伸，按这次真正需要的内容选择。需要同时处理几项时，说明最在意哪一项。
- **阅读感受**：勇敢提出抽象目标，例如“要像 xx 公众号的风格”“读起来要有 xx 的感受”。希望读者感到什么、听见怎样的声音，都可以写进要求；有参考文章时，也可以一并提供。
- **交付要求**：写清篇幅长度、信息保真程度等要求。例如是否保留全部事实和细节，是否允许压缩、补充或延伸，以及最终需要完整改稿还是其他交付形式。

## 5. 效果不稳定，可以换模型、换窗口试

同一份提示词的效果并不稳定。建议多换几个 AI，也可以多开几个聊天窗口，调整任务要求的写法，比较不同结果。某次表现不好，可以换一种说法，重新交代修改权限、重点和阅读感受，再试一次。

## 6. 进阶用法：单独使用其中一部分

分部分使用时，某一方面的效果往往更突出，但不够全面，适合已经熟悉这份提示词的人。

例如，只想集中梳理语流，可以单独复制“语流”部分，配合本次任务要求和原稿使用。需要同时照顾内容、语言、作者声口等多个方面时，再考虑使用完整提示词。
