# 中文写作优化

**原创作者：duke ｜ 联系与交流：微信公众号 Dukeland**

一套用于中文创作、改稿与去 AI 味的提示词，适合希望保留内容与作者声音，同时改善行文和语言的写作者。

有些稿件事实齐全、观点明确，读起来仍然费力：每段都重新起头，句子之间缺少接续；词语看似通顺，整句话却生硬；细节、态度和人物声音在反复修改中逐渐消失。这份提示词从作品所写的事情出发，把材料理解、全文展开、中文成句和作者的观察判断放在一起处理，帮助模型理解一篇文章应当怎样写好。

**[打开完整提示词](./提示词.md)**，复制后填写开头的“本次任务与特别要求”，即可配合原稿使用。下文介绍适用范围、原理、操作方式，以及三种可直接参考的任务写法。

## 可以用它改善什么

这套提示词适合处理已经有内容基础、但表达尚未充分实现的稿件，也可以在提供足够材料和明确任务后辅助起草。常见使用方向包括：

| 使用方向 | 希望获得的改善 |
| --- | --- |
| 全文语流梳理 | 让叙述、背景、判断与感受能够持续展开，减少反复起头、过渡报幕和段尾重复总结，保留有意义的停顿与回望。 |
| 中文表达优化 | 在具体语境中重组词序、句法和句群，改善翻译腔、抽象概念堆叠、搭配生硬等问题，使正式表达和日常表达都符合各自的文体。 |
| 作者声音与风格调整 | 根据原稿或参考作品，理解作者的关注、判断尺度、叙述距离与语言习惯，让风格进入选材和普通句段。 |
| AI 痕迹去除 | 处理空泛引入、机械排比、无依据的对照翻案、重复解释和概括等表达惯性，使文字回到具体内容。 |
| 内容展开与增补 | 在获得授权和必要资料后，补足重要经过、条件、比较与推理，让尚未充分表达的认识得到展开。 |

一次理想的改稿，应当让读者更容易理解事情、跟随文章，同时保有原稿中有价值的事实、区别、细节和意味。改善也可能体现在某个句群、一个段落或一处措辞上，改动幅度取决于任务。

实际效果受模型能力、原稿质量、参考材料和任务要求影响，并不稳定。风格模仿需要具体样本，事实准确性需要可靠材料与人工核对；“去 AI 味”的效果，应放在完整阅读中的语言、内容与作者声音里判断。

## 原理：理解作品，再让内容在中文中充分展开

整套方法首先要求模型理解作品所写的世界：人物处于什么条件中，事情怎样发生，各项材料有什么分量，作者依据什么作出判断，读者需要知道哪些前情。这样的理解参与结构、详略、措辞与分寸，也帮助模型辨认原稿中已经成立、应当保留的表达。

在这个基础上，语流、中文重写和直觉写作共同参与成文。

### 语流：让前文继续参与后文

读者会带着前文形成的认识、注意和感受继续阅读。语流关注事情、思考、声音和节奏怎样持续展开：背景在什么地方进入，判断如何获得依据，一个细节怎样改变后面的感受，哪里需要停留，哪里可以直接继续。它既涉及明确的事理关系，也涉及阅读中能够领会的情绪和注意变化。

### 中文重写：让完整意思在具体语境中成句

同一个意思，面对不同读者、处在不同文体和前后文中，会有不同的说法。中文重写要求词语、语序、主语显隐、句界和口气一起参与表达，处理整句话乃至相邻句群的组织。自然的中文可以是口语，也可以是充分展开的书面表达；取舍依据是此处的内容、声音和阅读需要。

### 直觉写作：让具体眼光参与取舍和判断

作者的知识、经验、审美和评价尺度，会影响他注意什么、在哪里停留、怎样比较，以及用什么分寸开口。直觉写作关注这些有来由的选择，让个人声音落实在内容和普通词句中。涉及现实人物、经历与事实时，表达仍须有材料依据。

三者相互影响：一个更准确的动词可能使关系变清楚，一次段落重组可能改变判断出现的位置，一处细节也可能使原先模糊的认识得到发展。提示词中的方法和反例用于帮助理解这些原理，最终以完整作品的表达和阅读效果判断取舍。

## 使用环境与模型选择

建议将提示词直接复制到各类 AI 或 Agent 的**聊天模式**中使用，优先选择网页端、聊天端。不要在各种 IDE、GPT Work 等工作环境中使用；WorkBuddy 勉强可用。也不要将这份提示词制作成 Skill，按作者的使用体验，这种方式的表现同样不理想。

## 开始使用

1. 打开 [提示词.md](./提示词.md)，复制完整内容。可以在文件页面切换到 Raw，查看便于复制的原始文本。
2. 在开头的“本次任务与特别要求”中，替换 `{{本次任务与特别要求}}`，写清本次目标、修改权限、重点、阅读感受和交付要求。
3. 在末尾的“原稿及必要材料”中，替换 `{{原稿及必要材料}}`，放入原稿。需要参考文风或补充事实时，一并提供材料，并分别标明“待改原稿”“风格参考”“事实资料”等用途。
4. 将填写后的整份内容发送到所选模型的聊天窗口。使用附件时，确认模型能够完整读取，并在任务要求中说明各附件的用途。
5. 阅读完整输出，对照原稿检查事实、信息保留、修改范围和阅读感受。需要继续调整时，指出具体问题及希望改变的方向。

## 任务要求怎样写

“本次任务与特别要求”决定了模型此次应该改什么、可以改到什么程度。先说明文章的用途和读者，再把以下四个方面写清楚。

### 1. 修改权限

结构逻辑、信息和观点、文本表达需要分别授权。

- **结构逻辑**：能否重选开头、调整章节、重排段落和材料次序，或改变论证的展开方式。
- **信息和观点**：哪些事实、细节和独立观点必须保留，是否允许删减或增补，能否发展、质疑或修正原有判断。允许增补时，应说明资料来源及可用范围。
- **文本表达**：可以调整到词句、句群还是整段重写，哪些直接引语、专有名称或已有表达必须保留。

允许润色，不等于允许重组文章；允许调整结构，也不等于允许改变事实或观点。权限可以因部分而异，例如“开头可以重写，案例部分只润色，结论的核心判断保留”。

### 2. 修改重点

根据稿件实际问题，选择风格模仿、语流梳理、文本润色、AI 痕迹去除、增补和延伸等方向，并说明优先次序。尽量指出问题发生在哪里，例如“背景介绍打断了叙述”“每段结尾都重复解释意义”“观点已经清楚，但中文句法仍然生硬”。

### 3. 阅读感受

可以大胆提出抽象目标，例如“接近某个公众号的叙述风格”“读起来像跟随采访者逐渐理解一个人”“保持专业判断，同时让非业内读者能够跟上”。这些目标能够帮助模型判断叙述距离、详略、节奏和口气。

有参考作品时，说明希望参考哪些特点，例如观察角度、材料安排、书面程度或幽默感。参考作品中的现实经历、人物关系和事实，应与待改稿件区分。

### 4. 交付要求

说明篇幅长度、信息保真程度和交付形式。例如，是否保留全部事实与细节，是否允许压缩，是否需要列出新增资料、未核实问题或修改说明。篇幅与信息要求发生冲突时，也可以明确哪一项优先。

## 使用案例：三种不同权限的任务写法

下面的案例用于示范如何填写“本次任务与特别要求”。可根据自己的稿件替换题材、篇幅和材料名称，再放入完整提示词的开头；原稿与参考材料仍放在末尾的对应位置。

### 案例一：内容已经确定，只做文本润色

适用于已经完成事实核对和内部确认的品牌文章、机构介绍或专业说明，重点是改善语言，同时严格控制改动范围。

```text
本次任务：润色一篇约 2000 字的产品介绍文章，面向初次了解产品的行业读者。内容和核心判断已经确认。

修改权限：
- 结构逻辑：保留章节、段落次序及原有论述关系，不重选开头，不改变文章重心。
- 信息和观点：保留全部事实、数据、产品能力、适用条件和原有观点，不新增资料，不扩大承诺。
- 文本表达：允许调整词语、语序、句界和相邻句子的接续。直接引语与专有名称保持原文。

修改重点：优先处理生硬句法、抽象名词堆叠和重复解释，使中文自然、准确，段落能够连续阅读。

阅读感受：清楚、专业、克制，让非专业读者能够理解产品及其使用条件；保留必要技术细节，不增加宣传口号。

交付要求：交付完整润色稿，篇幅控制在 1800—2200 字。信息保真优先于压缩篇幅；发现疑似事实问题时，不自行猜改，在正文之后单独列出。
```

这个案例只开放文本表达层面的调整。若实际需要改变章节或删减内容，应相应扩大授权。

### 案例二：重组采访特稿，并参考指定文风

适用于材料较充分、但开头、章节和叙述节奏尚未形成的稿件。可同时提供待改文章与几篇有代表性的风格参考。

```text
本次任务：重写一篇约 3500 字的人物采访特稿，面向对人物所处行业不熟悉的普通读者。所附材料 A 为待改原稿，材料 B 为风格参考文章。

修改权限：
- 结构逻辑：允许重选开头、重排章节和材料次序，调整现场、背景与分析出现的位置；保留原稿的核心问题和人物关系。
- 信息和观点：完整保留有独立意义的事实、经历、观点及必要限定。可合并重复说明，不删掉仅因看似偏离主线、却有助于理解人物处境的细节。不新增现场、心理、动机或未发生的结果。
- 文本表达：允许充分重写句段，人物直接引语保持原话，转述及作者判断保持归属清楚。

修改重点：先理顺整篇叙述和语流，再处理句法与 AI 表达惯性。让背景随人物经历进入，减少段首预告和段尾重复总结。

阅读感受：参考材料 B 的观察方式、叙述距离和语言节奏。希望读者像跟随采访者逐渐理解一个人，感到人物处境具体而复杂，行文从容但不拖沓。不要移用参考文章中的经历、事实或人物关系。

交付要求：交付约 3200—3800 字的完整成稿。保留关键事实、独立认识和重要细节；如确有无法同时满足的篇幅与保真要求，优先保真，并在正文后简要说明。
```

这个案例允许结构和语言大幅调整，同时保留事实、观点归属与人物经历的边界。风格参考需要落实到当前材料中。

### 案例三：依据补充资料，扩展一篇行业评论

适用于已经有初步观点、但比较、条件和推论尚未展开的文章。使用前准备好可供引用的资料，并明确原有观点是否允许调整。

```text
本次任务：扩展一篇讨论“AI 助手进入日常工作后，哪些环节仍需要人工判断”的评论。材料 A 为约 1800 字的原稿，材料 B 为产品测试记录，材料 C 为相关官方说明及来源链接。读者是实际使用 AI 工具的普通职场人。

修改权限：
- 结构逻辑：允许重组开头、比较次序和论证层次，使文章围绕原稿提出的问题充分展开。
- 信息和观点：允许依据材料 B、C 增补事实，发展比较和分析。补充材料支持时，可以修正原稿中过满或依据不足的判断；保留原稿的问题意识，并说明重要观点调整的依据。本次不另行联网补充资料。
- 文本表达：允许重写全文，保持术语、测试条件、数据口径、直接引语和来源准确。

修改重点：补清各项测试的条件与结果，解释哪些差异影响结论，展开原稿中尚未说透的推理。新增分析应有材料支持，区分实测结果、产品方说法和作者推断。

阅读感受：有明确判断，也让读者看得见判断怎样形成。专业内容解释到普通读者能够跟上；避免堆砌术语、拔高结论或把单次测试泛化为普遍能力。

交付要求：交付约 2800—3500 字的完整评论。正文中的新增事实标注来源；文后另列重要观点调整及仍需核实的问题。资料不足的部分保持具体的不确定性，不编造数据、案例或引用。
```

这个案例开放了信息增补与观点发展，但将依据限定在已提供的资料内。如果需要模型自行检索，应另行说明检索范围、来源要求和新增信息的核验方式。

## 输出不理想时，怎样继续调整

效果不稳定时，可以更换 AI，也可以新开几个聊天窗口，用同一份原稿尝试不同的任务要求。比较结果时，既看语言是否顺畅，也看事实与独立信息是否保留、全文是否仍在回答原来的问题、阅读感受是否接近目标。

后续要求可以直接针对已经看见的问题：

- 结构调整过大，就收紧章节和材料次序的修改权限。
- 重要细节被压缩，就指明需要保留的内容，以及信息保真和篇幅之间的优先关系。
- 只改词语、全文仍然断裂，就明确允许重组句群或段落，并指出需要持续展开的事情。
- 风格过重或语气失真，就补充参考样本，说明希望保留的特点和叙述距离。

比较不同模型或不同任务写法时，尽量使用同一份原稿。这样更容易判断差异来自哪里，也便于保留较好的结果。

## 进阶使用：单独调用某一部分

熟悉完整提示词后，可以根据任务单独使用语流、中文重写或直觉写作部分。按作者的使用体验，分部分使用时，某一方面的效果可能更突出，但覆盖不够全面。

例如，文章的事实、观点和语言已经较成熟，只需要梳理叙述的接续，可以复制“语流”部分，并配上明确的任务要求和原稿。任务中仍应写清哪些结构和内容可以调整，哪些必须保留。单独使用某一部分时，也应自行核对其他方面；涉及多方面改动的任务，优先从完整提示词开始。
